## О проекте

**LUMEN** — концепт сайта для клиники премиальной эстетической косметологии. Идея в том, чтобы сайт выглядел как дорогая кастомная разработка, а не как шаблон: много воздуха, мягкие линии, изящная типографика и ни одной резкой анимации.

> Это концептуальный проект. Клиника, цены, контакты и лицензия вымышлены.

## Что умеет сайт

| Блок | Что происходит |
|---|---|
| **Карта красоты** | Линейный SVG лица с шестью зонами: лоб, контур глаз, скулы, губы, овал, шея. При наведении зона подсвечивается, а рядом плавно меняется описание и список процедур. Работает с мыши, с клавиатуры и на телефоне. Клик по процедуре подставляет её в форму записи. |
| **Услуги** | Вкладки «Инъекции», «Аппаратная косметология», «Уход» со скользящим индикатором. Карточки гаснут и по очереди появляются через `opacity` и `transform`, без резких скачков. |
| **До / После** | Слайдер сравнения: перетаскивание мышью, пальцем, пером, а также управление стрелками, `Home` и `End`. |
| **Форма записи** | Поля с плавающими подписями и нижней линией, маска телефона `+7 (XXX) XXX-XX-XX`, проверка полей, выбор услуги из списка. |
| **Шапка** | Прозрачная при загрузке, при прокрутке превращается в матовое стекло. На телефоне бургер раскрывает меню круговой маской. |
| **Анимации** | Мягкое появление блоков при прокрутке через `IntersectionObserver`, один общий плавный `ease-in-out` на весь сайт. |

## Технологии

- HTML5
- Tailwind CSS (через CDN, своя палитра в `tailwind.config`)
- Vanilla JavaScript: независимые модули с комментариями на русском
- Кастомный CSS только для сложных анимаций и нестандартных элементов
- Лица, портреты и иллюстрации нарисованы SVG-кодом, поэтому сайт не зависит от внешних картинок

Весь сайт лежит в одном файле: `index.html`.

## Структура скриптов

| Модуль | Отвечает за |
|---|---|
| `initHeader` | матовая шапка и мобильное меню |
| `initReveal` | появление блоков при прокрутке |
| `initHero` | портрет в арке на первом экране |
| `initBeautyMap` | карта красоты и смена описания зон |
| `initServices` | вкладки и фильтрация карточек |
| `initBeforeAfter` | слайдер «До / После» |
| `initForm` | маска телефона, проверка и отправка |

## Запуск

```bash
git clone https://github.com/ВАШ-НИК/ИМЯ-РЕПОЗИТОРИЯ.git
cd ИМЯ-РЕПОЗИТОРИЯ
```

Откройте `index.html` в любом браузере. Сборка и сервер не нужны, но требуется интернет: из сети подгружаются Tailwind и шрифты.

## Как изменить под себя

- **Услуги и цены:** массив `SERVICES` в начале скрипта
- **Зоны лица и процедуры:** массив `ZONES` (названия процедур должны совпадать с названиями в `SERVICES`)
- **Свои фото:** вставьте ссылки в константу `PHOTOS` (`hero`, `before`, `after`), и рисунки заменятся фотографиями. Для слайдера нужны снимки одинаковых пропорций 4:5
- **Цвета и шрифты:** блок `tailwind.config` в `<head>`
- **Отправка заявок:** в обработчике формы (`initForm`) замените `console.log` на `fetch` в вашу CRM или почту
- **Контакты, ИНН и лицензия:** подвал страницы
